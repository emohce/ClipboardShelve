- Date: 2026-06-17
- Scope: 文件记录富预览扩展与首屏性能优化
- Status: automated verified, uTools real-file manual verification pending

## 本次目标

- 文件记录可在 Shift 预览中快速查看 PDF、Markdown、AsciiDoc、CSV、Excel、DOCX、常见文本、图片、PPTX/PPSX。
- PDF 首屏优先走 uTools Sharp 快路径，避免大文件首屏被 PDF.js 初始化拖慢。
- 其他文档类型改为异步读取和缓存，降低重复预览和大文件读取对 UI 的影响。

## 背景问题

- PDF 首屏原先依赖渲染进程读完整文件并初始化 PDF.js，真实大文件首屏慢。
- TXT/CSV/Office 文档同步读取或重复解析会放大 Shift 快速预览时的卡顿。
- PPTX/PPSX 原先没有可用内嵌预览，用户只能打开外部应用确认内容。

## 方案评估

- PDF: 优先使用 uTools 内置 Sharp 渲染第一页；失败时降级 PDF.js。未引入 MuPDF，避免 AGPL/商业授权风险。
- 文档: 使用 preload 提供异步文本首段和二进制读取，组件侧继续按类型选择轻量解析库。
- PPTX/PPSX: 使用 `jszip` 只读取 slide XML 文本节点，提供低保真快速确认，不追求版式还原。

## 最终采用方案

- [../../scripts/utools-runtime-assets.mjs](../../scripts/utools-runtime-assets.mjs:1) 暴露 `renderPdfFirstPagePreview`、`readTextPreviewFile`、`readBinaryPreviewFile`。
- [../../src/cpns/FileRichPreview.vue](../../src/cpns/FileRichPreview.vue:1) 先尝试 PDF Sharp 首屏，后台 PDF.js 补页；非 PDF 文档使用异步读取和缓存。
- [../../src/utils/filePreview.mjs](../../src/utils/filePreview.mjs:1) 新增 presentation 预览类型，支持 `.pptx` / `.ppsx`。
- [../../package.json](../../package.json:1) 新增 `jszip@3.10.1`，保留 `pdfjs-dist@2.6.347`。

## 影响范围

- Shift 文件预览的首屏速度、文件类型覆盖和重复预览缓存。
- uTools preload 对渲染进程暴露的只读文件预览 API。
- 构建产物新增按需加载的 `jszip` chunk。

## 风险与兼容性说明

- PPTX/PPSX 只展示文本摘要，不还原图片、动画、图表、母版或完整排版。
- `.ppt`、`.doc`、`.xls` 仍不支持内嵌预览。
- 超大 TXT/CSV 只读取首段，预览可能不是完整文件内容。
- PDF.js 旧版本用于兼容当前 Electron/uTools 外壳，并通过 `isEvalSupported: false` 规避 eval 路径。

## 遗留问题

- 仍需在 uTools 外壳用小 PDF、大 PDF、多页扫描 PDF、PPTX/PPSX 和多次 Shift 预览做真实文件复测。
- 若后续用户要求 Office 版式还原，需要另行评估外部转换或系统级预览能力，不能在当前低保真路径上直接承诺。
